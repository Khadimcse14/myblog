MEDGUIDE HEALTH - VERCEL DEPLOYMENT

This is a simple static medical blog website. No database or server is required.

Deploy to Vercel:
1. Create a folder/repository and upload all files.
2. Go to Vercel and choose Add New Project.
3. Import the GitHub repository OR upload the project folder if your Vercel workflow supports it.
4. Framework Preset: Other.
5. Build Command: leave empty.
6. Output Directory: leave empty / root.
7. Deploy.

Important:
- Replace MedGuide Health with your real website name.
- Replace hello@medguidehealth.com with your email.
- Replace sample articles with medically reviewed content before publishing.
- Update Privacy Policy according to your actual analytics, cookies, forms, ads and hosting setup.
